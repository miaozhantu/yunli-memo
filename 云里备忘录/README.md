# 云里备忘录

> 一个打算长久用下去的微信小程序手账本。日程、笔记、账单，装在同一本纸里。

**云里备忘录**刻意做减法：没有账号、没有云同步、不取你的头像昵称。所有内容只写在手机本地存储里，换机或清缓存就丢失——这一点在设置页里也写明了。文案不喊口号、不阴阳怪气，只把数字翻译成一句人话。

---

## ✨ 特性

- **数据只存本机**：不上传、不云同步、不登录，隐私自己掌握。
- **五套主题**：米黄纸 / 奶茶碎花 / 机械黑金 / 牛皮纸 / 夜读，只换配色不改结构。
- **剪报按时段换内容**：洗牌袋算法保证「换一批」不会重复蹦出刚看过的。
- **记账**：金额输入严格清洗（只认数字、小数两位）、按发生时间倒序、Canvas 月报、比上月对比、自定义标签、搜索。
- **日程**：24 小时可滚动时间轴、任意日期直选（不用一天天点）、15/30/60 分钟粒度、打勾即完成、过期自动翻篇。
- **笔记**：列表倒序 + 标签筛选 + 搜索；编辑页素纸 + 本地录音（不上传）+ 模拟翻译气泡。
- **周模板**：按星期翻页填格，一键同步到今天及以后。

## 🎨 五套主题

- **米黄纸**：默认配色，暖一点的纸，白天不刺眼。
- **奶茶碎花**：奶茶色纸底，撒一层很淡的小碎花，不闹。
- **机械黑金**：近黑底压细斜纹，金色只用在关键处。
- **牛皮纸**：像用了很久的本子，颜色沉、边角旧。
- **夜读**：关灯后纸变深色，字还是暖的。

## 🧱 架构与约定

- 存储读写只允许在 `utils/store.js`，页面禁止直接调 `wx.getStorageSync`。
- 提示统一走 `utils/feedback.js` + `<paper-toast>`，禁止 `wx.showModal` 做反馈。
- 底部导航用 `custom-tab-bar`（首页 / 设置 / 我的），tab 页在 `onShow` 里 `getTabBar().setData({selected:n})`。
- 自定义导航栏 `components/nav-bar`，高度按胶囊按钮实测计算。
- 文案取用走洗牌袋（抽空才重洗）；剪报内容在 `utils/content.js`（四时段八组 101 条）。
- 图标由脚本生成 PNG base64 进 `utils/icons.js`，按主题分五份。
- 时间轴粒度存 `CONFIG.slotMinutes`；字符串时间用 `startMin/endMin` 分钟数。

## 🛠 本地运行

用 **微信开发者工具** → 「导入项目」→ 选择本目录（`project.config.json` 已就位）。

如需导出干净的上传包（不含 `assets` / `tools` / 记忆等）：

```bash
python tools/package.py
# 输出 E:\build\云里备忘录\ 以及同名 .zip
```

## 🔒 隐私说明

本项目所有内容（日程、笔记、账单、录音）**仅存储于本机 Storage**，不上传任何服务器。清缓存、卸载或换机后数据即丢失；设置页提供 JSON 导出以便自行备份。
